# Changelog

All notable changes to Wotchi will be documented here.

## 0.1.0-beta.1 — 2026-08-08

- Added the reviewed Express 4/5 and NestJS 10/11 integration examples.
- Added configuration, setup, testing, security, and release documentation.
- Added the protected, manual GitHub Actions release workflow with npm OIDC staging for later releases.
- Recorded the founder's documented Wotchi trademark-risk acceptance for this beta; this is not legal clearance.

- Added the Phase 1 package foundation for `@futurewindai/wotchi`.

- Added ESM, CommonJS, declaration, lint, format, test, audit, and package smoke-check workflows.
